# Santafé — extensão 2.0.0

Compatível com o núcleo Santafé 3.0.0 e SLS 1.1.0. Migre projetos2.1 antes
de editar e executar usando este contrato. Listas usam `[]`; colares brutos
usam `[=[...]=]` ou níveis maiores; gabaritos usam um acento grave e `®`/`Ⓡ`.
ONFÉ tem diagnóstico de dados e não executa código.

VS Code: instale o VSIX do portal com “Extensions: Install from VSIX…”.
A identidade permanece `santafe.santafe`. Sublime Text: instale `Santafe`
pelo repositório próprio divulgado no portal, ou copie o pacote manual para
Installed Packages. O Sublime requer o cliente LSP para os diagnósticos;
ative “Santafé: Ativar diagnósticos SLS”. Ctrl+B usa o núcleo instalado.

Nenhum núcleo está embutido na extensão. Instale-o junto com as ferramentas:
`santafe-sls.exe` no Windows, `santafé-sls` no Linux/macOS. Se houver mais de
uma versão, configure o caminho da distribuição3.0. Os comandos de paleta
suave HTML/JS permanecem opcionais. Trust continua necessário no VS Code.

A publicação nos catálogos externos é independente do pacote do portal.
